# Console-sniffer
Программа перехватчик входящих и исходящих Ethernet пакетов.

Простой консольный сниффер сетевых пакетов под Linux на C.

## Сборка и запуск

Для работы с сырыми сокетами требуются права суперпользователя (`sudo`).

```bash
# Переход в папку с содержимом программы
cd src

# Сборка
make

# Запуск со всеми интерфейсами
sudo ./sniffer

# Запуск с фильтрами (например: слушать eth0, только TCP, подробный вывод)
sudo ./sniffer -i eth0 -t -v -d
```

### Флаги

* -i <интерфейс> — слушать конкретную сетевую карту (например, eth0).
* -t — показывать только TCP.
* -u — показывать только UDP.
* -v — подробный вывод (показывает TTL и флаги TCP: SYN, ACK, FIN).
* -d — вывести тело пакета (байты данных в HEX).
* -h — справка.
